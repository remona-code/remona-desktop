# reMona Desktop

reMona bir **Agent IDE**: sağlayıcı ekleyip (OpenCode Zen, NVIDIA, OpenAI, Anthropic…) sohbet + coder kullanabileceğiniz, gömülü tarayıcı ve alt ajanlar barındıran bir Windows masaüstü uygulaması.

## İndirme

Kurulum dosyaları yalnızca **Releases** bölümünde yayınlanır: **[Son sürüm](../../releases/latest)**

| Dosya | Açıklama |
| --- | --- |
| `reMona-Setup-<sürüm>.exe` | Windows x64 kurulum dosyası (NSIS) |
| `reMona-Setup-<sürüm>.exe.blockmap` | Otomatik güncelleme için delta haritası |

## Kurulum notları

- Kurulum imzasız olduğu için Windows SmartScreen **"Bilinmeyen yayıncı"** uyarısı gösterebilir: *Daha fazla bilgi* → *Yine de çalıştır*.
- Kurulum tek kullanıcı içindir (per-machine değil); yönetici izni gerekmez ve hedef klasörü kurulum sırasında seçebilirsiniz.

Bu depo yalnızca yayınlanan sürümleri (derlenmiş kurulum dosyalarını) barındırır; **kaynak kod paylaşılmaz**.
